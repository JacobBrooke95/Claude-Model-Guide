API Pricing 

Claude API list price per million tokens for the current lineup. Lighter bars are input tokens, solid bars are output tokens. Dashed marks show each tier's price before its most recent change.

Per million tokens. Lighter bar: input. Solid bar: output. Dashed mark: price before the last change.

Opus 5.5 (Sep 22, 2026) is the first Opus price cut in ten months: $4 in / $20 out, down from $5 / $25, with cache reads at $0.20 (from $0.50 — now 5% of the input price rather than 10%) and cache writes at $5. Anthropic's headline is that it costs 40% less than Opus 5 on typical workloads; only the 20% list cut is on this chart, and the rest of that claim is the cheaper cache plus fewer tokens per task, which the bars can't show. Fast mode drops in step, to $8 in / $40 out. The cut also widened the Fable premium from 2× to 2.5× on both input and output, until Fable 5.2's own cut on November 9 brought it back to 2×.
Sonnet 5.5 (Sep 28, 2026) takes Sonnet 5's bar at the same price: $2 in / $10 out, cache reads $0.20 at launch (the standard 10% of input) and cache writes $2.50, with the Batch API at $1 / $5. So the bar didn't move. Anthropic's "up to 30% less per task" claim rests entirely on Sonnet 5.5 using fewer tokens for the same work, which a per-token chart can't show. One side effect of Opus 5.5's 5% cache rate: at Sonnet 5.5's launch both models charged the same $0.20 per million for a cache read (Sonnet 5.5's has since been halved; see Haiku 5.5 below). Sonnet 5 stays on the API at $2 / $10.
Haiku 5.5 (Oct 7, 2026) cuts the Haiku price by 90%: $0.10 in / $0.50 out, down from Haiku 4.5's $1 / $5, with cache reads at $0.01 (10% of input) and 5-minute cache writes at $0.125; the Batch API halves both rates, to $0.05 / $0.25. It is the only current Claude model priced by prompt length rather than with flat long-context pricing: a request whose prompt runs past 100k tokens (cache reads and writes count toward that) is billed $0.50 / $2.50, cache reads $0.05, for the whole request. The bar shows the up-to-100k rate. Anthropic's announcement puts the average saving over Haiku 4.5 at about 75% (90% on requests up to 100k tokens, 50% above). Haiku 4.5 stays on the API at $1 / $5. Haiku 5.5's bars ($0.10 and $0.50) are too short to read on this scale, so they are drawn at a minimum height with the exact price above. The same announcement halved Sonnet 5.5's cache-read price, from $0.20 to $0.10 per million (5% of input, Opus 5.5's rate), effective October 7; Anthropic puts that at about 20% off most agentic work. The Haiku 5.5 system card's cost figures use that updated rate.
Fable 5.2 (Nov 9, 2026) is the first Fable price cut: $8 in / $40 out, down 20% from the $10 / $50 that Fable 5 and Fable 5.1 both carried, which puts Fable back at 2× Opus 5.5 on input and output. Cache reads are $0.20 per million, still 2.5% of the input price; cache writes are $10 (five-minute) and $16 (one-hour); the Batch API is $4 / $20 and fast mode $16 / $80. The full 1M-token context window is billed at the standard rate. Fable 5.1 had moved no bar on this chart: it held $10 / $50 and made its cut in cache reads, from $1 to $0.25 per million (2.5% of input, against 10% on most other Claude models and 5% on Opus 5.5). Fable 5.1 and Fable 5 stay on the API at their old rates. Claude Mythos 5.2 is priced identically to Fable 5.2 but is restricted to organizations verified through Anthropic's verification programs, as Mythos 5.1 was to trusted-access programs and Mythos 5 to Project Glasswing partners, so it gets no bars of its own.
Sonnet 5's $2 in / $10 out was announced as introductory pricing through Aug 31, 2026, with a step back up to Sonnet 4.6's $3 / $15 due Sep 1; Anthropic cancelled the increase and made $2 / $10 the standard price, so the intro overlay this chart used to carry is gone. Sonnet 5.5 kept that rate.
The dashed marks are each tier's list price before its most recent change, with the percentage under the model name. Every tier's last change is now a cut: Fable was the one tier that had never changed price, until Fable 5.2. The last rise was Haiku 4.5 (Oct 15, 2025), which launched at $1 / $5, 25% above Claude 3.5 Haiku's $0.80 / $4; Haiku 5.5 reversed it. Older changes are left off to keep the scale readable, notably Opus's cut from $15 / $75 with Opus 4.5.
Opus pricing dropped from $15/$75 to $5/$25 with Opus 4.5 (Nov 2025) and held there through Opus 5, which stays on the API at those rates (fast mode $10 in / $50 out). Cache hits cost 10% of the input price on every model except Opus 5.5 and Sonnet 5.5 (5%, Sonnet 5.5 since October 7), Fable and Mythos 5.1 and 5.2 (2.5%), and the Batch API halves both rates.

What the axes measure. The Anthropic ECI (AECI) is how Anthropic tracks "the rate of capability improvement of our models over time". It follows the method of Epoch AI's Epoch Capabilities Index, which fits one score per model from its results across many benchmarks, but it is fed with Anthropic's internal benchmark results. The scale is pinned at two points: Claude Sonnet 3.5 at 130 and GPT-5 at 150. Everything here is first-party, from section 2.3.5 of the Fable 5.2 / Mythos 5.2 system card.
One fit, and only one. The card's fit of November 6 covers 371 benchmarks and 1,026 models, and it says: "Because each refit reestimates the whole scale, AECI values from this fit are not comparable to the AECI values in earlier system cards… Comparisons between models should be made within a single fit." So this chart plots that one table and nothing else. In it: Mythos Preview 165.71, Mythos 5 168.68, Opus 5 169.40, Mythos 5.1 172.62, Opus 5.5 174.78 and Mythos 5.2 177.12. Earlier cards gave other numbers for the same models on other fits (Opus 5.5 was 169.36 in its own card), and gave Sonnet 5.5 167.93, Haiku 5.5 167.11 and Opus 4.8 155.5, each on a different fit. None of those numbers is plotted as published, and Opus 4.8 and Opus 4.7 have no point at all. When the next card ships, the whole series will be replaced, not extended.
The two diamonds are this site's estimates, not Anthropic's figures. Sonnet 5.5 and Haiku 5.5 were each scored only in their own card's fit, but each of those cards also gives Opus 5.5 on the same fit, and Opus 5.5 is in the November 6 table at 174.78. Shifting by Opus 5.5's move: the Sonnet 5.5 card has Opus 5.5 at 169.12 (+5.66), so Sonnet 5.5's 167.93 becomes about 173.6; the Haiku 5.5 card has Opus 5.5 at 174.56 (+0.22), so Haiku 5.5's 167.11 becomes about 167.3. One overlap model each is thin evidence. Where three overlaps are known, between the September 18 fit and this one, the shift differs by model (Opus 5 165.18 → 169.40, Mythos 5.1 168.12 → 172.62, Opus 5.5 169.36 → 174.78: +4.2, +4.5, +5.4), so each estimate carries a dotted ±1.0 whisker, which is that spread and not a confidence interval. They are drawn hollow, off the line, and only one hop is taken: Opus 4.8's 155.5 is not estimated. Its card does give Mythos Preview on the same fit (158.3), but that fit used 11 benchmarks and sits five refits back, and a single overlap across that distance is too weak to carry a number.
The bars. The thin bar is the card's global 95% interval: the uncertainty in a model's absolute position, from 100 refits that each drop a fifth of the benchmarks. It is wide (Mythos 5.2: 172.42 to 182.94) and, in the card's words, "largely shared across frontier models", so overlapping thin bars do not mean two models are tied. The thick bar is the local interval, how precisely the fit separates a model from the average of the three Claude releases before it (Mythos 5.2: 175.75 to 178.48).
The hollow points are read off a figure. The card's table stops at Mythos Preview, but its Figure 2.3.5.3.B plots eight earlier frontier models by name without printing their values. Seven are shown here as measured from that figure: Claude 3 Opus about 124.7, Claude 3.5 Sonnet (new) 133.7, Claude 3.7 Sonnet 141.3, Opus 4 144.7, Sonnet 4.5 147.7, Opus 4.5 152.2, Opus 4.6 157.3. The same measurement lands within 0.1 of the table for the three tabled models the figure also labels, so treat them as good to a few tenths, with no interval. Claude 3.5 Sonnet is 130 by definition.
Dates differ from the card's. Anthropic plots each model on the day it became available internally; this page uses public release dates, as every other chart here does. The line joining the points is only there to lead the eye. It is not Anthropic's fitted trend, and slopes should not be read off it.
The trend claim, as the card makes it. Mythos 5.2 is "about 11 points above the historical trend line and 2.3 points above Claude Opus 5.5". Fitting a single change of slope, "the fitted slope change is about 1.88x (95% CI: 1.62x-2.28x)", at a breakpoint in October 2025. "This is nominally below the 2x threshold set in our RSP, but the estimate varies considerably depending on which benchmarks and model snapshots are included in the fit." The card adds that it does not think this shows Mythos 5.2 crosses that threshold.
Not on the chart. An unreleased internal research model, scored on 15 benchmarks, is in the same table at 178.78 (173.75 to 185.18); it has no public release date, so it gets no point. Mythos is the restricted twin of each Fable release, and the index is reported for the Mythos model only: Fable 5.2 is not scored separately. No Haiku, and no Sonnet after 4.5, appears in this fit's table or figure, which is why those two are estimates (card read November 9, 2026).

These are all 25 AECI values printed in the text or tables of Anthropic's system cards, for ten models (PDFs re-read November 9, 2026). Colours are families, as above: Mythos teal, Opus violet, Sonnet coral, Haiku green. Hover or tap a small dot for the card and date it came from; the table has every value.
What the poles show. A model's published score climbs after release, by more than the gap between neighbouring models. Mythos 5 was 161.29 in its own card and is 168.68 now: 7.4 points in five months with no change to the model. Mythos 5.1 has gone from 161.98 to 172.62 in ten weeks, Opus 5 from 162.1 to 169.40, and Opus 5.5 was published four times in seven weeks, at 169.36, 169.12, 174.56 and 174.78. Between one refit and the next the models scored in both rose together, by 4.5 to 6.1 points from the Mythos 5.1 card to the September 18 fit and by 3.8 to 5.4 from there to November 6. The large dot is at the foot of its pole except where a model was once re-scored below its original before rising: Mythos 5 (161.29, then 159.46 in the Mythos 5.1 card) and Opus 5 (162.1, then 160.73 in the same card), each by more than a point, and Opus 5.5 by a quarter-point (169.12, hidden behind its large dot).
Which dots can be compared. The ringed dot at the top of a pole is the model's score on the November 6 fit. Six models have one (Mythos Preview, Mythos 5, Opus 5, Mythos 5.1, Opus 5.5 and, as its large dot, Mythos 5.2), and those six are the mutually comparable numbers, the same ones as in the first chart. The large dots are not: each is from a different fit, so read left to right they are not a trend.
Why the numbers move, in the cards' words. "Because each refit re-estimates the whole scale, AECI values from this fit are not comparable to the AECI values in earlier system cards." Each refit drops, adds and corrects benchmarks (338 in the Mythos 5.1 card's basket, 374 on September 18, 371 on November 6, with fixes for "misconfigured or low-signal benchmarks"), then re-pins the two anchors, Claude Sonnet 3.5 at 130 and GPT-5 at 150. The frontier sits well above the upper anchor, where, the Opus 5.5 card says, models "move together" and the uncertainty "grows with distance above the upper anchor". Earlier cards described these shifts as "well within our reported error bars"; the published 95% intervals are 8 to 12 points wide at the frontier.
Where the estimates above come from. The two diamonds in the first chart use dots on Opus 5.5's pole: 169.12 (from the Sonnet 5.5 card) and 174.56 (from the Haiku 5.5 card), each against the ringed 174.78.
Gaps are gaps. Mythos Preview (April 7) and Opus 4.7 (April 16) have no large dot because their own cards printed no AECI value, only slope ratios and distances from trend; their first published scores, 158.3 and 154.1, came seven and six weeks later in the Opus 4.8 card, from a reduced set of 11 evaluations. Opus 4.8, Sonnet 5.5, Haiku 5.5 and Mythos 5.2 are lone large dots: no later card has re-scored them, which for the first three also means no score on the current fit. The Opus 5 card's Mythos 5 figure (161.3) is its predecessor's 161.29 rounded, so that dot sits on the large one. Every card also has a figure showing earlier models as unlabelled dots; apart from the November 6 figure read for the first chart, those were not measured, so a missing dot means "not printed", not "not scored". Sonnet 5 has no value anywhere: its card says "we did not compile AECI for Sonnet 5".

SWE-bench Pro is Scale AI's harder successor to SWE-bench. Its problems come from actively maintained repositories, need larger multi-file patches, and have less of their ground truth public. A task counts only if the model's patch makes the project's own tests pass. Higher is better.
Fable 5.2 (Nov 9, 2026) tops the chart at 93.0%, 3.1 points over Opus 5.5 and 11.8 over Fable 5.1 ten weeks earlier. Fable 5 to 5.1 had moved 1.2 points, so nearly all of the Fable line's gain is in this one release, and it puts Fable back ahead of Opus for the first time since Opus 5.5 shipped. Opus 5.5 (Sep 22) is second at 89.9%, 10.7 points over Opus 5. The Opus line has climbed 37.9 points in ten months, from Opus 4.5's 52.0%, and more than half of that came in the last two releases. Unlike Verified, this eval still has room at the top. Sonnet 5.5 (Sep 28) scores 81.3%, 18.1 points over Sonnet 5 and level with Fable 5.1's 81.2 at a fifth of the price. It is the largest single step any Sonnet has taken here. Haiku 5.5 (Oct 7) scores 64.8%, the first Haiku on this chart: 16.5 points behind Sonnet 5.5 and 1.6 ahead of Sonnet 5's 63.2.
Why this chart moved from SWE-bench Verified. Anthropic stopped reporting Verified with Fable 5.1: its launch table, and the Opus 5.5 and Sonnet 5.5 system cards, carry no Verified figure. Verified had also saturated, with Opus 5 at 96%, where the remaining tasks are widely argued to be noise and mislabelling. Every generally available Claude model since Opus 4.7 has a Pro figure in its own or a later system card. For the record, the retired Verified series was: Opus 4 72.5, Opus 4.1 74.5, Opus 4.5 80.9, Opus 4.6 80.8, Opus 4.7 87.6, Opus 4.8 88.6 and Opus 5 96.0; Sonnet 4 72.7, Sonnet 4.5 77.2, Sonnet 4.6 79.6 and Sonnet 5 85.2; Haiku 4.5 73.3; Mythos Preview 93.9; Fable 5 95.0; Mythos 5 95.5.

Opus 4.6's 53.4 is from the Mythos Preview and Opus 4.7 cards, since its own has none. Sonnet 4.6's 58.1 is from the Sonnet 5 card. Opus 4.5's 52.0 is its no-thinking run; with 64k thinking it scored 51.6, and the higher run is plotted, as on the other charts. Fable 5.2's 93.0 is from Table 8.1.A of the Fable 5.2 and Mythos 5.2 card, at max effort. Mythos 5 (80.3%) shares Fable 5's release date and is left off to avoid an exact overlap; Mythos 5.1 and Mythos 5.2 have no figure of their own. Not plotted: Haiku 4.5 and Sonnet 4.5, which Anthropic never scored on Pro (the Haiku 5.5 card leaves Haiku 4.5's cell blank). ARC Prize calls ARC-AGI-3 an interactive reasoning benchmark: agents "explore novel environments, acquire goals on the fly" and learn inside each game, "instead of solving static puzzles". The score is not a pass rate. In ARC Prize's words, "a 100% score means AI agents can beat every game as efficiently as humans", and every environment is one people can solve, which is what the dashed line at the top marks. It is a definition, not a measured human panel: the data files have a human-panel row for ARC-AGI-1 and -2 and none for ARC-AGI-3. Results are on the semi-private set of 55 games.

What counts as a listing date. A lag is counted only where the listing date is actually known: the board states it (an update stamp, an entry's creation date, a verification date), or this site read the board on release day and the entry was already there. Those are the solid figures, and only they feed the typical lag.

The dashed figures are upper bounds. For most older entries the only date on record is the day this site first read the board and found the entry, or the day the row was first committed to this page. The board may have listed the model any time before that, so “≤6d” means “listed within six days of release, possibly sooner”. Upper bounds are never averaged. A board with fewer than three known dates shows “too few observations” instead of a median.

Pending means the board was read on the date shown and had no entry for that model; “never” means no check has been recorded. Days waiting are counted from the release date to today. The Vals board's update stamps for Fable 5.1 and Sonnet 5.5 fall a day before each model's public release; they are kept as stated and counted as zero days. Vending-Bench Arena rounds carry dates, but a round is dated to the release it is pinned to rather than to when its result went up, so no Arena date is treated as a listing date.

Not every board feeds a chart. OSWorld-Verified and swebench.com are tracked for context: the OSWorld and SWE-bench Pro charts plot Anthropic's own reported figures. LMArena refuses automated reads and the OSWorld-Verified board loads its data dynamically, so both show as unchecked rather than pending. Mythos models are restricted to verified organizations, no public board has run one, and they are left out of the table.
