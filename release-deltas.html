How to read this

Every row is one printed figure from the newer card, paired with the matching figure for its predecessor. Largest moves come first in each category: percentage figures by points moved, everything else by relative change. Select a row to see how each card describes the measurement.

  • The comparability rule. Two figures get a delta only if they sit under the same canonical metric, name the same sub-evaluation and measure, belong to the same model line (Fable against Fable, Mythos against Mythos), and nothing in their descriptions conflicts: effort level, thinking on or off, tools, search, safeguards, strict against partial scoring, single against multi-turn, a named subset, or a different task-set size. Both values must parse as one number in the same unit. A figure the card only shows in a chart, a range, or a "less than" bound gets no delta.
  • Same-card comparison means the newer card restates the predecessor's score in its own table, so both numbers come from one setup. That figure is preferred, and it can differ from what the predecessor's own card printed; the row detail shows both. Card-to-card means each number comes from its own card. Those are held back when the newer card says its setup changed, when it re-measures another earlier model at a different value than that model's card printed, when one card prints several variants and the other does not say which it means, or when the two cards describe the evaluation differently and the figure jumps by more than 25 points.
  • Not comparable rows show both values side by side with the reason and no delta. New and dropped count figures, not metrics, so a metric both cards report can still add or lose a variant.
  • Better or worse is colored only where the card says which way is good or the measure makes it plain (accuracy, resolve rate, attack success rate, over-refusal). Welfare, interpretability, evaluation-awareness and the RSP capability evaluations are never judged, and neither is a bare "score" outside the capability benchmarks. The arrow always shows which way the number went.

Limits. The matching is done by rule on short text descriptions, so it is conservative and still fallible: it will miss true pairs whose wording differs, and a card-to-card pair can pass every check while the harness, prompt or grader changed without the card saying so. Treat card-to-card deltas as weaker evidence than same-card ones. Older pairs have few deltas because the early cards put many results only in charts, which were recorded without a number. Some values were read off figures and are approximate (marked ≈). Every number is Anthropic's own first-party measurement of its own model, extracted from the PDFs by machine, so check the cited section before relying on one.
