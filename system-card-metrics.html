How this was built

Each system card PDF was converted to text and read end to end by a Claude agent, which recorded every evaluation the card reports for its own model or models: capability benchmarks, safeguards and refusal rates, agentic and prompt-injection safety, alignment and behavioral audits, honesty, model welfare, interpretability, and the Responsible Scaling Policy evaluations for CBRN, cyber and autonomy. It then audited each section for figures it had missed. A second pass grouped the same evaluation across cards, so a benchmark renamed between cards counts once.

  • A new version is a new metric. SWE-bench Verified and SWE-bench Pro, or Terminal-Bench 2.0 and 2.1, are separate rows. Effort levels, thinking budgets and subsets are variants within one row.
  • A filled dot means the card prints a figure for that metric. A hollow dot means it reports the evaluation without a printed number, for example a result shown only in a chart image, a qualitative finding, or a threshold pass/fail.
  • Only the card's own models are recorded. Cards also quote competitors and earlier Claude models; those figures belong to the other model's own card.
  • Joint cards (Opus 4 with Sonnet 4, and both Fable/Mythos releases) are one column each, colored by the first-named family.
  • Machine extraction from PDFs can misread a table. Every figure cites its card section, so check the source before relying on a number.

The Markdown version of this index, with a page per card, is in the system-cards folder of this site's repository.
